# 単語帳クイズ（GitHub Pages対応・スマホ向けWebアプリ）

スプレッドシート（CSV）で管理した単語帳をもとに、日→英・英→日の4択クイズができるアプリです。
HTML/CSS/JSのみで動く静的サイトなので、GitHub Pagesにそのまま公開できます。

## 機能

- **n個のスプレッドシート（CSV）を連結**して1つの単語帳として扱う
- 章（chapter）ごとの**出題範囲選択**（チェックボックスで複数選択）
- 出題方向の切り替え（日→英／英→日／両方）
- 正解・不正解のあと、答え合わせを見せるための**ディレイ**を挟んで次の問題へ（`config.js`で秒数変更可）
- 回答終了後、**まちがえた問題だけ**再挑戦できる
- 回答終了後、**同じ問題セット**をもう一度解き直せる
- **「単語帳」タブ**：クイズとは別に、日本語⇄英語の対応を一覧でスクロールして眺められる画面
- **「お知らせ」**：CSV更新などをユーザーに伝える項目。`data/announcements.json` を編集してコミットするだけで内容を更新でき、過去のお知らせも一覧で確認できる
- 白／黒2テーマをワンタップで切り替え
- スマホのホーム画面に追加すればアプリのように起動（`manifest.json`）

## ファイル構成

```
index.html          画面のHTML
style.css            デザイン
app.js               クイズ・単語帳・お知らせのロジック
config.js            ← スプレッドシート(CSV)・お知らせのURLを登録する場所
data/*.csv           サンプルの単語データ（3章分）
data/announcements.json  お知らせデータ
manifest.json        ホーム画面追加用の設定
```

## スプレッドシートのフォーマット

CSVの1行目（ヘッダー）は次の列名にしてください（順番は自由）。

| 列名 | 内容 | 必須 |
|---|---|---|
| `chapter` | 章番号（半角数字） | ○ |
| `ja` | 日本語（問題・答え） | ○ |
| `en` | 英語（問題・答え） | ○ |
| `wrong_en_1`〜`wrong_en_3` | 「日→英」で出す誤答（英語）3つ | 推奨 |
| `wrong_ja_1`〜`wrong_ja_3` | 「英→日」で出す誤答（日本語）3つ | 推奨 |

- 1つのCSV（＝1つのスプレッドシート）の中に複数の章の単語が混ざっていてもOKです。章の集計は`chapter`列の値から自動で行われます。
- `wrong_en_*` / `wrong_ja_*` が3つ揃っていない行は、自動的に他の単語からランダムに補って4択にします（誤答は用意しておくのが確実です）。
- サンプル: `data/chapter1.csv` を参照してください。

## 自分のスプレッドシートを使う（n個登録する）

`config.js` の `SHEET_CONFIG` を編集します。

```js
const SHEET_CONFIG = [
  { label: "単語帳1", url: "data/chapter1.csv" },
  { label: "単語帳2", url: "data/chapter2.csv" },
  { label: "単語帳3", url: "https://docs.google.com/spreadsheets/d/e/xxxxx/pub?output=csv" },
  // 必要なだけ追加できます（n個）
];
```

### Googleスプレッドシートを直接読み込む場合

1. スプレッドシートを開く
2. 「ファイル」→「共有」→「ウェブに公開」
3. 公開するシート（タブ）を選び、形式を **「カンマ区切りの値（.csv）」** にして公開
4. 発行されたURLを `config.js` の `url` に貼り付ける

※ シートを編集すればアプリ側は再読み込みするだけで最新内容になります。

## GitHub Pagesで公開する手順

1. このフォルダの中身をそのままGitHubリポジトリにコミット＆プッシュする
2. リポジトリの **Settings → Pages** を開く
3. 「Source」を `main` ブランチ／ルート（`/`）に設定して保存
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになります
5. スマホのブラウザでアクセスし、「ホーム画面に追加」するとアプリのように使えます

## お知らせの更新方法

`data/announcements.json` を編集してGitHubにコミット（プッシュ）するだけで、アプリの「🔔お知らせ」に反映されます。

```json
[
  { "date": "2026-09-18", "title": "第4章を追加しました", "body": "スプレッドシートに新しい章を追加しました。" },
  { "date": "2026-09-10", "title": "公開しました", "body": "単語帳クイズを公開しました。" }
]
```

- 新しい項目を配列の先頭・末尾どちらに追加してもOKです（`date`の新しい順に自動で並び替わります）
- 過去のお知らせもすべて画面上に残るので、削除しない限り一覧で確認できます
- 新しいお知らせが増えるとベルのアイコンに赤い丸（未読サイン）が表示されます

## 見た目や動作の調整

- 正解時／不正解時のディレイ：`config.js` の `FEEDBACK_DELAY_CORRECT` / `FEEDBACK_DELAY_WRONG`（ミリ秒）
- 配色・フォント：`style.css` 冒頭の `:root` 内の変数
